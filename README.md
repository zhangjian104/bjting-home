# 白洁听书

**白洁听书**是一个面向中文听众的在线听书与有声内容平台，侧重深夜陪伴与情感向收听体验。你可以在浏览器中收听中文**有声小说**、书单与合集内容，也可以使用**听书**、搜索等方式快速找到想听的作品，适合睡前放松或长时间**声音陪伴**。

**官方网站（在线收听）：** [https://www.bjting.com](https://www.bjting.com)

若链接无法打开，也可在搜索引擎中检索「**白洁听书**」进入官网。

---

## 平台能做什么

- **在线听书**：在网页内播放有声内容，无需安装客户端即可使用（支持将站点加入主屏幕的 PWA 体验）。
- **发现内容**：通过推荐、书单/合集等形式浏览中文有声读物与相关栏目。
- **多端适配**：采用响应式布局，兼顾桌面端与移动端的浏览与播放操作。
- **界面体验**：毛玻璃（Glassmorphism）风格界面，支持浅色/深色主题与系统主题跟随。

## 与本开源仓库的关系

本仓库 **bjting-home** 是白洁听书站点所使用的 **Web 前端工程**（Vue 3 + Vite），业务数据由独立后端 API 提供。欢迎开发者查阅源码、提交 Issue 或 PR。

- **源码仓库**：[zhangjian104/bjting-home](https://github.com/zhangjian104/bjting-home)

## 本地开发（面向贡献者）

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

构建与部署请参考项目内 `package.json` 中的 `build`、`deploy` 脚本；对接后端时需按 `.env.example` 配置本地或生产环境变量。
